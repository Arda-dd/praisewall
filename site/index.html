Praisewall collects testimonials from your customers with a simple link, lets you approve the best ones, and shows them on any website with one line of code. Self-hosted, so the data stays yours.

This is the real widget

The same embed your visitors would see. Switch the layout and theme.

One line to add it to your site

The widget renders inside a shadow root, so your site's CSS can't break it and it can't break yours.

<div data-praisewall="https://your-praisewall.com/api/walls/orbit" data-layout="masonry"></div>
<script src="https://your-praisewall.com/widget.js" async></script>

How it works

Three steps, no account on someone else's platform.

1

Share a link

Each wall gets a page like /c/orbit. Send it to customers by email, chat or after a purchase.

2

Approve the best

New testimonials wait in your inbox. Approve, reject or pin them to the top. Add ones from email or LinkedIn by hand.

3

Show them anywhere

Embed the widget, share the public wall page, or use the JSON API to build your own design.

A calm admin, a friendly form

Light and dark mode, on desktop and phone.

Run it in two minutes

With Docker, or on any host with PHP 8.3+. Full guide in the README.

# Get the code and create a key
git clone https://github.com/Arda-dd/praisewall.git && cd praisewall
echo "APP_KEY=base64:$(openssl rand -base64 32)" > .env

# Start it, then open http://localhost:8080 to create your account
docker compose up -d
